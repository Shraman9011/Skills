# Android QA Report

## Summary
App, version, device(s), personas, dates, tool versions.

## Test matrix
| Persona / test | Result (passed, failed, skipped, inconclusive) | Steps used | Goal met |
| --- | --- | --- | --- |

## Findings
For each finding:
- ID
- Type: bug, usability, crash, security
- Severity
- Confidence: confirmed, likely, suspected, inconclusive
- Reproduction steps
- Expected vs actual (use the `--expect` text)
- Screenshots and log excerpts
- Suggested fix
- Regression test idea

## Usability findings
Where a newcomer got stuck, steps taken versus a reasonable number, abandoned goals.

## Security findings
Category, evidence, verification status, remediation.

## Not covered
Backend, hardware-specific behavior, anything skipped.

Unexecuted tests are skipped or inconclusive, never passed. Save the report next to the logs in `.qa-run/`.
