# Personas

| Persona | Behavior |
| --- | --- |
| Curious newcomer | Reads labels, explores every tab, reads error messages. |
| Impatient user | Skips onboarding and tutorials, taps the first obvious button, abandons quickly. |
| Careless user | Enters empty, wrong, very long, or odd values; taps twice; hits back at bad moments. |
| Cautious user | Denies every permission, declines optional steps, wants to leave and delete data. |
| Interrupted user | Rotates, backgrounds the app, loses network, returns later. |

Give each run a plain goal: for example, sign up, find a key feature, change a setting, and log out. Different personas on the same app often reveal different problems.
